# 打字训练 Typing Trainer

一个简单的网页打字训练工具，支持中文短句、中文短篇文章、中文长篇文章、中文标点、英文基础、中英混合，以及自己粘贴文章练习。

在线体验：

https://3531059882.github.io/typing-trainer/

## 功能

- 支持多种练习模式
- 支持中文输入法，不会把拼音输入过程算作错误
- 打错字不会自动删除，会在文章中直接标出错误位置
- 回车不会被误算为错误字符
- 支持粘贴自己的文章进行练习
- 显示正确率、速度和错误数量

## 使用方法

1. 打开网页
2. 选择练习模式
3. 点击开始或直接输入
4. 按照上方文章内容打字
5. 打错的位置会自动标红提示
